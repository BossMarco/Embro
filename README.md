# Embro Xpress website

Next.js starter repository for the Embro Xpress website. It is linked to the Vercel project `blmrockers-projects/embro-xpress`.

Client and website-direction research is in [docs/client-research.md](docs/client-research.md).

## Local development

```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
